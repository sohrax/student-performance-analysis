# Student Performance Analysis & Prediction System

## 📌 Overview
This project analyzes and predicts student performance based on multiple factors such as study hours, sleep duration, and attendance percentage.

## 🚀 Features
- Multi-variable Linear Regression Model
- Interactive user input for prediction
- Data visualization using graphs and bar charts
- Performance evaluation (Good / Average / Needs Improvement)

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## 📊 Insights
- Higher study hours generally lead to better performance
- Attendance plays a crucial role in academic success
- Balanced sleep also impacts results

- Use real-world dataset (Kaggle)
- Add web interface (Streamlit)
